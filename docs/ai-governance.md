# ProfitLeak AI Governance & Human-in-the-Loop Approval

## 1. Governance Principles
1. **Deterministic Authority**: All financial calculations are authoritative in PostgreSQL. AI provides analysis and recommendations.
2. **Action Candidate Lifecycle**:
   - `PROPOSED`: Generated by an agent with estimated financial impact and risk tier.
   - `PENDING_APPROVAL`: Queued in Action Center for operator review.
   - `APPROVED`: Authorized by human operator; triggers deterministic execution.
   - `REJECTED`: Dismissed by operator with logged reason.
   - `EXECUTING`: Business service currently processing the side-effect.
   - `COMPLETED`: Finished with immutable audit trail.
   - `FAILED`: Execution rejected by backend domain validation.

3. **High-Risk Thresholds**:
   - Any financial impact > 5,000,000 UZS requires Owner or Finance Manager role.
   - Security IP blocks or rate limits require Security Admin confirmation.
